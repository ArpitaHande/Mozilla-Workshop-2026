A small, interactive website that explains what we're doing and why. Nothing
here needs to be installed or built — it's plain **HTML, CSS and JavaScript**.

## Your task today

Add your name to the CONTRIBUTORS list in script.js (or to [`CONTRIBUTORS.md`](CONTRIBUTORS.md) if you'd rather not touch the JS) and open a pull request. Once your PR is merged and you deploy your fork, you'll see your name on the contributor wall of your own live site (if you added it via script.js).

## Try it locally

1. Clone your fork.
2. Open `index.html` in your browser. That's it.

## Files in this repo

| File | What it is |
|---|---|
| `index.html` | The page structure and content |
| `style.css` | Colors, layout, animations |
| `script.js` | Interactivity, and the CONTRIBUTORS list that powers the contributor wall |
| `CONTRIBUTORS.md` | Backup way to add your name if editing script.js feels tricky |
